## 1. Executive Summary & Architecture Overview

The image generation pipeline in `asVideoStudio` is architecturally split into two layers:
1. **The Legacy API Layer (`motores/imagen_openai/imagen.py`)**: Designed originally for OpenAI DALL-E / `gpt-image-2` using the `/v1/images/edits` endpoint with multi-part reference attachments (`image[]`).
2. **The Resilient Provider Adapter Layer (`motores/imagen_openai/yieldchat_imagen.py`)**: Designed as an alternative provider router supporting Agnes AI, SiliconFlow, Google Gemini, and Pollinations.ai.

### The Actual Execution Path
In `motores/imagen_openai/imagen.py` (lines 600–609):
```python
if not api_key and (not _claves_declaradas() or (hasattr(_cuentas()[0], 'clave') and _cuentas()[0].clave == "banana-flux")):
    from motores.imagen_openai import yieldchat_imagen
    return yieldchat_imagen.generar_imagen_yieldchat(prompt, referencias, tamano=tamano)
```
In the active workspace:
- `secretos/claves.json` has `"openai": []` (no OpenAI API keys configured).
- `secretos/.env` contains no `OPENAI_API_KEY`.
- Consequently, **100% of image generation calls route directly into `yieldchat_imagen.generar_imagen_yieldchat`**.

### Critical Forensic Findings
1. **Severe Prompt Truncation & Overwrite**: `yieldchat_imagen.py` enforces a hardcoded 280-character limit (`limpiar_y_condensar_prompt`, lines 150–151) and injects rigid boilerplate (such as `"chrome robot panels, glowing cyan details"` for any 3D style). This completely strips and destroys all style guide rules, character anchor descriptors, and composition details.
2. **Ephemeral URL 404 Failures**: Agnes AI (`agnes-image-2.1-flash`) was called without `"response_format": "b64_json"`. Agnes returned short-lived CDN URLs on `platform-outputs.agnes-ai.space`. When fetching these URLs via secondary HTTP GET, transient replication delays or expiration caused 404 errors, causing generations to silently fail.
3. **Verified Base64 Direct Delivery**: Live testing confirmed that passing `"response_format": "b64_json"` to Agnes AI returns 200 OK with full base64 image data (~818 KB to 1.7 MB for 1024x576 PNGs) in ~8–10 seconds with **zero 404 risk** and **zero external CDN dependencies**.
4. **Current Provider Quotas**:
   - **Agnes AI**: Authenticated, active, responsive ($0.00 tier).
   - **SiliconFlow**: Authenticated but returns **HTTP 402** (`{"code": 30001, "message": "Sorry, your account balance is insufficient"}`).
   - **Google Gemini**: Returns **HTTP 400** (`"Image generation is not available in your country"`) due to EU/Spain regional restrictions in Google AI Studio, and **HTTP 429** quota exhaustion.
   - **Pollinations.ai**: Authenticated with API key, active as fallback.
5. **Cache Pollution by Emergency Canvases**: Forensic analysis of `banco/imagenes` revealed **253 corrupted emergency canvases** (10–13 KB placeholder images with gold border RGBA `(212, 175, 55, 120)` generated by `_crear_lienzo_cinematografico`). Because `_producir_imagen` in `pasos/p6_assets.py` unconditionally saves any returned PNG to disk cache, these degraded placeholders were cached permanently and re-served to the user.

## 2. Deep Dive: Engine Modules & Provider Adapters

### 2.1. Agnes AI Adapter (`_intentar_generar_agnes`)
- **Location**: `motores/imagen_openai/yieldchat_imagen.py`, lines 387–441
- **Endpoint**: `https://apihub.agnes-ai.com/v1/images/generations`
- **Model**: `agnes-image-2.1-flash`
- **Auth**: Bearer token via `AGNES_API_KEY` (read from environment, `secretos/.env`, or `secretos/claves.json`)
- **Request Structure (Current)**:
  ```python
  payload = {
      "model": "agnes-image-2.1-flash",
      "prompt": prompt_completo,
      "size": img_size
  }
  ```
- **Flaws Identified**:
  1. Does **not** include `"response_format": "b64_json"`.
  2. Passes `prompt` through `enriquecer_prompt()`, which runs `limpiar_y_condensar_prompt()`, stripping the prompt down to < 280 characters.
  3. Relies on `data_arr[0].get("url")`. When fetching `img_url`, any HTTP non-200 (such as 404) triggers a silent fall-through returning `(None, None)` without retrying.
  4. Notice that lines 416–426 **already contain the decoding logic** for `b64_json`:
     ```python
     b64 = data_arr[0].get("b64_json")
     if b64:
         raw = base64.b64decode(b64)

         ...
         return out.getvalue(), "Agnes Image 2.1 Flash (Agnes AI)"
     ```
     The base64 decoding code was already written, but the payload simply forgot to request `response_format: "b64_json"`.

### 2.4. Pollinations.ai Adapter (Legacy)
- **Location**: `motores/imagen_openai/yieldchat_imagen.py`, lines 666–704
- **Endpoints**:

  - Free: `https://image.pollinations.ai/prompt/{encoded}?width={width}&height={height}&nologo=true&seed={seed}`

## 4. Investigation: Ephemeral URLs & 404 Delivery Errors in Agnes AI

### 4.1. The Root Cause of 404 Errors
When `response_format` is omitted from the request to `https://apihub.agnes-ai.com/v1/images/generations`, Agnes AI returns an object pointing to an external object storage CDN:
```json
{
  "data": [
    {
      "url": "https://platform-outputs.agnes-ai.space/images/t2i/task_eGWtf3yZiE8jqKYF84FfEA1OazTlcjnn/output_a8aa7d48e7f54a34a5d645cbdfd4cd3d.png",
      "b64_json": "",
      "revised_prompt": "..."
    }
  ]
}
```
In real-world generation runs:
1. **Asynchronous Edge Invalidation / Replication Lag**: The image generation job completes in the GPU worker and writes the database record with the planned CDN URL. However, the physical file upload to `platform-outputs.agnes-ai.space` has a replication delay of 500ms to 2s. An immediate `requests.get(img_url)` from the client hits a **404 Not Found**.
2. **Extremely Short Retention / Ephemeral Garbage Collection**: Files stored on `platform-outputs.agnes-ai.space` are ephemeral worker artifacts that expire or are pruned aggressively.
3. **Brittle Error Handling in `yieldchat_imagen.py`**:
   Lines 428–437:
   ```python
   elif img_url:
       img_resp = requests.get(img_url, timeout=25)
       if img_resp.status_code == 200:
           ...
           return out.getvalue(), "Agnes Image 2.1 Flash (Agnes AI)"
   ```
   If `img_resp.status_code` is 404, there is **zero retry logic**, no logging of the status code, and no sleep backoff. It immediately drops to line 440, returning `(None, None)`.
4. **Cascading Degradation**: When Agnes returns `(None, None)`, `generar_imagen_yieldchat` falls back to SiliconFlow (which fails with 402), then Gemini (fails with 400/429), then Pollinations (times out or rate-limited), and finally degrades to `_crear_lienzo_cinematografico` (emergency canvas).

## 5. Solution: Enforcing `response_format: b64_json` & Direct Base64 Delivery

### 5.1. Live Validation
When the request payload includes `"response_format": "b64_json"`:
```python
payload = {
    "model": "agnes-image-2.1-flash",
    "prompt": prompt,
    "size": img_size,
    "response_format": "b64_json"
}
```
Agnes AI returns:
```json
{
  "created": 1759778870,
  "data": [
    {
      "b64_json": "iVBORw0KGgoAAAANSUhEUgA...",
      "url": "",
      "revised_prompt": "..."
    }
  ],
  "task_id": "task_..."
}
```
- The image data is embedded directly in the JSON response.
- **No secondary HTTP GET** to `platform-outputs.agnes-ai.space` is executed.
- **Zero 404 errors** are possible.
- The latency of the secondary connection handshake is eliminated.

### 5.2. Decoding & Direct-to-Disk Streaming
The base64 string decodes directly in memory via `base64.b64decode(b64_str)` and can be verified by PIL (`Image.open(io.BytesIO(raw))`) to ensure PNG header integrity (`\x89PNG\r\n\x1a\n`) before being returned or written directly to the target file path.

## 6. Survey of Provider Fallback & Quota Mechanisms

### 6.1. Current Provider Routing Logic in `yieldchat_imagen.py`
The current routing is controlled by `_obtener_generador_preferido()` (reading `ajustes.json` -> `"generador_imagen"`, defaulting to `"agnes"`):

| Mode | Primary | 1st Fallback | 2nd Fallback | 3rd Fallback | Last Resort |
|---|---|---|---|---|---|
| `agnes` (default) | Agnes AI | SiliconFlow | Gemini | Pollinations | Adopted Ref / Emergency Canvas |
| `siliconflow` | SiliconFlow | Agnes AI | Gemini | Pollinations | Adopted Ref / Emergency Canvas |
| `auto` | Agnes AI | SiliconFlow | Gemini | Pollinations | Adopted Ref / Emergency Canvas |

### 6.2. Weaknesses in the Current Fallback System
1. **Lack of Provider Cooldown / State Tracking**: Unlike `imagen.py` which maintains a `_Cuenta` class with `sin_saldo` and `sin_saldo_desde` (cooldown of 1800s), `yieldchat_imagen.py` is completely stateless between calls. Even though SiliconFlow returns HTTP 402 on every single call, `yieldchat_imagen.py` attempts it again on every subsequent scene, incurring network latency and logging spam.
2. **Missing Reference Forwarding**: Neither Agnes AI nor SiliconFlow receive reference images. They are called purely as text-to-image endpoints. The references passed to `generar_imagen_yieldchat` are completely ignored until the engine fails and calls `_resolver_referencia_real`.
3. **No Retry on Transient 5xx Errors**: If Agnes AI experiences a transient 502/504 gateway error, it does not retry with exponential backoff (e.g. wait 2s and try again); it immediately jumps to the next provider.

## 7. Forensic Analysis of Image Saving, Disk Storage & Emergency Canvases

### 7.1. Emergency Canvas Generation
When all network providers fail, `yieldchat_imagen.py` falls back to:
1. `_resolver_referencia_real` (lines 177–227): Searches `proyectos/*/estilo/aportadas/*` or `banco/presets/*/*.png` for any PNG > 35 KB and selects one using `hash(prompt) % len(candidatas)`.
2. `_crear_lienzo_cinematografico` (lines 229–266): If no candidate files exist, it creates a synthetic PNG:
   - For 2D/stick: White background with green bottom stripe `(120, 180, 120)` and black baseline `(20, 20, 20)`.
   - For other styles: Dark gradient with a gold rectangular border at `(24, 24)` colored `(212, 175, 55, 120)`.

### 7.2. Cache Pollution in `banco/imagenes`
In `pasos/p6_assets.py` (`_producir_imagen`, lines 2955–3011):
```python
png, meta = imagen.generar(prompt, referencias, quality=p["calidad"], tamano=tamano)
os.makedirs(os.path.dirname(destino), exist_ok=True)
with open(destino, "wb") as fh:
    fh.write(png)
medios.copiar(destino, cacheada)
```
- `_producir_imagen` calculates a SHA-1 hash `firma` of the prompt + parameters.
- It writes the generated bytes to `destino` and copies it to `banco_imagenes/{firma}.png`.
- **Crucial flaw**: `_producir_imagen` never inspects `meta["modelo"]` or image content. Even if `meta["modelo"]` is `"yield-canvas (HD)"`, it treats the emergency canvas as a legitimate `"origen": "generada"` result and permanently caches it in `banco_imagenes`!
- On subsequent runs:
  ```python
  if os.path.exists(cacheada):
      medios.copiar(cacheada, destino)
      return {"origen": "cache", "firma": firma, "coste": 0.0}
  ```
  The pipeline reads the emergency canvas from cache and re-serves it forever, never attempting to generate the real image again.

## 8. Architectural Recommendations & Implementation Blueprint

To fulfill the requirements of R3 and the project goals, the following architectural refactoring is proposed for the implementation phase:

### 8.1. Refactor `_intentar_generar_agnes` in `motores/imagen_openai/yieldchat_imagen.py`
1. **Force `"response_format": "b64_json"`** in the POST payload.
2. **Eliminate prompt condensation for Agnes**: Stop passing prompts through `limpiar_y_condensar_prompt()`. Allow the full technical prompt (up to 2,000+ characters) to reach Agnes AI intact.
3. **Add Transient Retry**: Add up to 2 retries with backoff (e.g. 2s) for network timeouts or HTTP 502/503.
4. **Direct Base64 Extraction**: Extract `data[0]["b64_json"]`, decode with `base64.b64decode`, validate PNG magic bytes, and return PNG bytes.

```python
# Proposed Agnes generation logic sketch
def _intentar_generar_agnes(prompt, width, height, tamano="apaisado"):
    api_key = _obtener_clave_agnes()
    if not api_key:
        return None, None

    url = "https://apihub.agnes-ai.com/v1/images/generations"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "Content-Type": "application/json"
    }
    img_size = "1024x576" if tamano in ("apaisado", "16:9") else "1024x1024"
    
    # Send full un-truncated prompt
    payload = {
        "model": "agnes-image-2.1-flash",
        "prompt": prompt.strip(),
        "size": img_size,
        "response_format": "b64_json"
    }
    
    for intento in range(2):
        try:
            resp = requests.post(url, json=payload, headers=headers, timeout=40)
            if resp.status_code == 200:
                data = resp.json()
                data_arr = data.get("data") or data.get("images") or []
                if data_arr and data_arr[0].get("b64_json"):
                    raw = base64.b64decode(data_arr[0]["b64_json"])
                    im = Image.open(io.BytesIO(raw))
                    if im.size != (width, height):
                        im = im.resize((width, height), Image.Resampling.LANCZOS)
                    if im.mode != "RGBA":
                        im = im.convert("RGBA")
                    out = io.BytesIO()
                    im.save(out, format="PNG")
                    return out.getvalue(), "Agnes Image 2.1 Flash (Agnes AI)"
            time.sleep(1.5)
        except Exception as e:
            print(f"[imagen_yieldchat] Agnes AI intento {intento+1} error: {e}", flush=True)
            time.sleep(1.5)
    return None, None
```

### 8.2. Provider Health & Cooldown Tracking
Implement a cooldown cache for exhausted providers:
- If SiliconFlow returns HTTP 402, record a timestamp and skip SiliconFlow for the next 30 minutes (`COOLDOWN_SIN_SALDO_S = 1800`), immediately routing to Agnes AI or Pollinations without wasting network time.
- If Gemini returns 400 (geo-blocked) or 429, mark it disabled for the session.

### 8.3. Safe Prompt Pipeline Differentiation
- If the target engine is **Pollinations.ai** (which requires HTTP GET URL encoding): use a specialized URL-safe condenser only for Pollinations.
- If the target engine is **Agnes AI** or **SiliconFlow** (which accept JSON POST payloads): transmit the full structured English prompt without any 280-character truncation or template override.

### 8.4. Guard Against Emergency Canvas Cache Pollution in `pasos/p6_assets.py`
In `_producir_imagen`:
```python
# Guard: never cache emergency canvases or adopted references as valid generated scenes
es_fallback = meta.get("modelo") in ("yield-canvas (HD)", "referencia-estilo (Adoptada)")
if not es_fallback and len(png) > 25000:
    medios.copiar(destino, cacheada)
```
This ensures that if a network outage causes a fallback canvas to be rendered, it is **never saved to `banco_imagenes`**, allowing subsequent runs to regenerate the true image automatically once connectivity or quota is restored.
