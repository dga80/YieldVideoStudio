## 2. Logic Chain

1. **Step 1 (Emergency Rejection Mechanism)**:
   - Observation 1.1 shows that `validar_imagen` samples `[(24, 24), (25, 25), (w - 25, 25), (25, h - 25), (w - 25, h - 25)]` for pixels with `abs(r - 212) <= 25 and abs(g - 175) <= 25 and abs(b - 55) <= 25`.
   - All 407 disk emergency canvases generated by `yieldchat_imagen._crear_lienzo_cinematografico` have this exact border.
   - Therefore, real emergency canvases are rejected with 100% accuracy and 0% false positives on presets.

2. **Step 2 (DNA Poisoning Prevention)**:
   - In `extraer_adn_estilo` and `extraer_anclas_personaje`, `validar_imagen` is executed at the very entrance (before cache checks or API calls).
   - If `valida` is False, the functions immediately branch to fallback anchor / preset DNA synthesis, skipping `gemini_cliente.ejecutar` and `_guardar_cache_huella`.
   - Therefore, emergency canvases can never reach the multimodal vision model, nor can emergency canvas features pollute the DNA cache.

3. **Step 3 (Cache Layer Integrity & Persistence)**:
   - `extraer_adn_estilo` checks `BANCO/dna/estilo_{huella}.json` using `huella_fichero(ruta_lamina)`.
   - A cache hit bypasses all external calls and returns in ~0.3 ms.
   - Mutating the file changes `huella_fichero`, guaranteeing stale cached data is never returned for modified assets.

4. **Step 4 (Self-Healing Fallback)**:
   - When cache JSON is read, `leer_json(cache_h)` catches decoding errors and returns `None`.
   - `_es_adn_valido` enforces strict schema conformance: dict type, presence of all 8 keys, non-empty strings, and valid `#[0-9a-fA-F]{6}` hex codes.
   - Any corrupt cache fails `_es_adn_valido` and triggers regeneration. Upon regeneration, `_guardar_cache_huella` overwrites the corrupted file on disk with clean, valid JSON.

## 3. Caveats

1. **File Size Gate for Emergency Detection**:
   `validar_imagen` executes the pixel border check only if `size < 50 * 1024`. All real emergency canvases generated by the system are between 4 KB and 15 KB (even at 4K resolution it is ~38 KB). However, if an emergency canvas were intentionally padded with >50 KB of auxiliary metadata chunks, it would not trigger this check. This is an intentional optimization to avoid opening large megabyte image files for pixel sampling.
2. **Offline API Mocking in Unit Suite**:
   Live Gemini vision network calls were mocked in the automated unit suite to avoid rate limits and token expenditure. Offline fallback and mocked responses thoroughly tested all branching paths.
