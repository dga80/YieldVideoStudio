#### C. Diagnóstico: ¿Por qué los planos se veían como un lienzo oscuro con borde dorado?
* Al inspeccionar la pestaña de **Imágenes / Assets**, los 120 planos del vídeo mostraban un diseño esquemático oscuro con marco dorado y el rótulo `YIELD STUDIO · PLANO [ID]` en lugar de las ilustraciones finales.
* **Causa raíz:**
  1. `asVideoStudio` no tenía clave de OpenAI en `secretos/claves.json`, por lo que activó el motor libre alternativo (**Nano Banana** en `yieldchat_imagen.py`).
  2. El proveedor de GPU en la nube detrás de Nano Banana (**Pollinations.ai**) empezó a emitir errores `HTTP 402 / 500 (Payment Required)` ante llamadas anónimas no autenticadas.
  3. Para evitar que el proceso abortara y se perdiera el proyecto, el mecanismo de contingencia (`_crear_lienzo_cinematografico`) generó automáticamente tarjetas de maquetación HD con el encuadre y el prompt para que el montaje y los subtítulos pudieran continuar.

#### D. Clarificación Arquitectónica: ¿Qué es Pollinations frente a YieldChat?
* **Pregunta del usuario:** *¿Para qué quieres la API de Pollinations? ¿No puedes usar la API de YieldChat?*
* **Aclaración:** YieldChat no dispone de servidores propios de generación de imágenes con GPU. En el backend de YieldChat ([`image_tools.py`](file:///Users/danidev/Desktop/YieldChat/backend/image_tools.py)), la función `generar_imagen()` cuando se le pide el modelo `"google-banana"` **hace exactamente una llamada a Pollinations.ai**. Por tanto, la API de imágenes de YieldChat es un intermediario que consulta a Pollinations.

### 3. Modificaciones Técnicas Aplicadas en el Código

En el archivo [`motores/imagen_openai/yieldchat_imagen.py`](file:///Users/danidev/Desktop/asVideoStudio/motores/imagen_openai/yieldchat_imagen.py):

1. **Extracción precisa del prompt de escena:**
   * **Antes:** La expresión regular tomaba erróneamente una instrucción negativa fija (`"en la escena: o esta, o lo representan..."`), provocando que todos los planos tuvieran un texto idéntico.
   * **Ahora:** Extrae directamente el bloque `Scene:` de cada plano (ej. el choque múltiple en Los Ángeles, la UCI de Tokio, el pánico en Wall Street, etc.).
2. **Control de Concurrencia (Semáforo de hilos):**
   * Se incorporó `threading.Semaphore(2)` para limitar a un máximo de 2 peticiones en paralelo y evitar que el servidor externo corte la conexión por ráfagas masivas.
3. **Soporte nativo de API Key:**
   * Se implementó `_obtener_clave_banana()`, que lee la clave desde variables de entorno (`POLLINATIONS_API_KEY`, `BANANA_API_KEY`) o desde [`secretos/claves.json`](file:///Users/danidev/Desktop/asVideoStudio/secretos/claves.json) en los campos `pollinations`, `banana` o `nano_banana`.

#### Cómo reactivar la generación de imágenes:
1. Obtener una clave gratuita en **[enter.pollinations.ai](https://enter.pollinations.ai)** (o utilizar una clave de OpenAI si se prefiere).
2. Añadirla a `secretos/claves.json`:
   ```json
   {
     "pollinations": {
       "clave": "TU_API_KEY_AQUI"
     }
   }
   ```
3. Desde la interfaz web en la pestaña de **Imágenes**, pulsar en regenerar/rehacer los planos o ejecutar la tarea de assets.
